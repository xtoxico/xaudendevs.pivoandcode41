# Prompt 01: Generar contratos TypeScript

Lee estos documentos antes de responder:

- `docs/specs/auth_service.md`
- `docs/specs/auth_contracts.md`
- `docs/specs/auth_architecture_rules.md`
- `docs/specs/system_instructions.md`

Tarea:

Genera únicamente los contratos TypeScript del módulo de autenticación.

Archivos permitidos:

- `src/auth/auth.contracts.ts`
- `src/auth/auth.errors.ts`

Restricciones:

- No generes controller.
- No generes facade.
- No generes repository.
- No generes app de Express.
- No implementes lógica de negocio.
- No cambies los nombres de interfaces definidos en la Spec.

Antes de generar el código, indica brevemente qué reglas de la Spec estás aplicando.
